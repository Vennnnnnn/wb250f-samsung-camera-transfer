# Samsung WB250F Camera Transfer

A simple macOS app for connecting to a Samsung WB250F camera in MobileLink mode, browsing photos, and downloading full-resolution images.

## Requirements

- macOS
- Python 3.12
- Samsung WB250F
- Mac connected to the camera's Wi-Fi network

## Setup

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/samsung-camera-transfer.git
cd samsung-camera-transfer
```
